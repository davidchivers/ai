# Code notes

Do not copy the Dropbox code tree wholesale into this repo.

The Dropbox `code/` folder currently mixes:

- source Stata scripts
- source Python scripts
- source R scripts
- LaTeX source
- logs
- generated figures
- generated tables
- compiled LaTeX artifacts
- workbooks

Before adding code here, copy only the intended production scripts and keep data paths local and ignored.

Use:

- `access/` for Dewey and Dropbox data access scripts or instructions
- `analysis/` for cleaned analysis scripts

Do not add raw data, generated row-level outputs, or credentials.

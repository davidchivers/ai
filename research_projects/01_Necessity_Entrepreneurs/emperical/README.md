# Emperical

Markdown-only workspace for the identification side of the Necessity Entrepreneurs project.
The goal is to tighten the link between the paper's formal definition of necessity
entrepreneurship and the empirical objects we can estimate cleanly.

## File map

- `01_project_overview.md`: core question, current paper logic, and why measurement is hard.
- `02_literature_and_synthesis.md`: what the main proxy families identify and where they fail.
- `03_formal_design_bridge.md`: model-to-data bridge and the estimands worth targeting.
- `04_empirical_notes.md`: candidate empirical strategies.
- `05_research_plan.md`: current preferred path, fallback, and next tasks.
- `06_data_inventory.md`: inventory of the project's current public-data assets and missing high-value data.
- `07_variable_map.md`: model objects mapped to observables, with limits of each proxy.
- `08_opportunity_self_employment_note.md`: why starts-small, low capital, and self-employment do not cleanly separate necessity from opportunity.

## Working rule

Treat this folder as a brainstorming workspace, not as the canonical project tracker.
If we lock an empirical design here, we can then sync the chosen path back into
`research_projects/01_Necessity_Entrepreneurs/STATUS.md`.

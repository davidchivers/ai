# Self-employment recession windows

Annual-average CPS self-employment rates from the person-level companion series.

## 2000-2002 recession window

- `Total self-employment`: 10.72% -> 10.65% (-0.07 percentage points)
- `Unincorporated`: 7.46% -> 7.27% (-0.19 percentage points)
- `Incorporated`: 3.26% -> 3.38% (+0.12 percentage points)

## 2007-2010 Great Recession window

- `Total self-employment`: 11.06% -> 10.70% (-0.36 percentage points)
- `Unincorporated`: 7.13% -> 6.96% (-0.17 percentage points)
- `Incorporated`: 3.93% -> 3.73% (-0.19 percentage points)

## 2019-2022 pandemic window

- `Total self-employment`: 9.98% -> 10.44% (+0.46 percentage points)
- `Unincorporated`: 6.06% -> 6.24% (+0.18 percentage points)
- `Incorporated`: 3.92% -> 4.20% (+0.28 percentage points)

## Why this reset exists

The project drifted into the network-figure branch. That work was useful for learning what the
scene graphs can and cannot show, but it is not the current bottleneck. The live paper is still the
scene-emergence paper, and the workflow should reflect that.

1. Main paper first.
   The core paper remains `scene -> genre emergence`, centered on local spawning flow,
   target-genre active bands, and target-genre multi-band musicians.
2. Draft before decoration.
   The active writing object is still the markdown paper spine in `06`-`08`. The next gains should
   come from tightening those sections, not from opening more figure branches.
3. Appendix support in parallel.
   Keep the sample-construction and variable-measurement appendix material close enough to the draft
   that the pipeline is auditable.
4. Sidecar stays secondary.
   `scene -> band success` remains live as a data workflow, but it is still too thin for a real
   regression result.
5. Network figure is parked.
   The Helsinki graph work should stay exploratory unless a better direct-control workflow makes it
   easy to produce a paper-quality figure.

objects in `09` and `11`, it is probably not the right next task for this project right now.

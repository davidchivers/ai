# Shared templates

Templates in this folder are generic starting points. Keep them reusable; filled-in project documents should live in the relevant project folder, not in `_shared/`.

## Current templates

- `referee_response_template.tex`: base skeleton for new referee responses.
- `referee_response_example.tex`: worked example showing the expected structure and tone.
- `reference_checklist_template.csv`: starter checklist for literature verification. Copy this into a project-local `literature/checklist/reference_checklist.csv` before editing.
- `notes/`: numbered templates for the standard notes-phase files:
  - `01_project_overview_template.md`
  - `02_literature_and_synthesis_template.md`
  - `03_model_notes_template.md`
  - `04_empirical_notes_template.md`
  - `05_research_plan_template.md`

## Selection rule

- If the file is a reusable skeleton, keep it here.
- If it already contains project-specific content, move it into that project.

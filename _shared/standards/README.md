# Shared standards

Standards in this folder are the canonical operating rules for recurring workflows.

## Current standards

- `AGENT_LIBRARY_REVIEW.md`: quarterly maintenance checklist for `_shared/`.
- `codex_away_workflow.md`: bounded unattended-work rules and stopping discipline.
- `code_calibration_standard.md`: conventions for calibration code review and alignment.
- `environment_workflow.md`: Windows, worktree, storage, and environment-selection rules.
- `notes_phase_standard.md`: flat notes-phase layout, file roles, and migration rules.
- `paper_project_structure_standard.md`: canonical paper-project folder structure.
- `project_status_standard.md`: how `STATUS.md` should be structured and maintained.
- `referee_response_standard.md`: formatting and workflow rules for referee responses.

## Selection rule

- If the file defines a rule, checklist, or canonical convention, keep it here.
- If it is a worked example or starting skeleton, move it to `templates/`.

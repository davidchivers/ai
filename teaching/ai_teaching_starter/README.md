# AI teaching starter packs

This folder prepares two starter distributions for teaching:

- `starter_basic/` for lightweight onboarding
- `starter_advanced/` for full workflow preferences

Current status:

- The old standalone GitHub repo `davidchivers/ai_install` has been deleted.
- These folders remain the local source material for starter packs.
- Starter ZIP downloads are served as static website assets from `other/davidchivers_site/ai_install/downloads/`.

This repo is for starter-pack distribution only. The public website should live in the dedicated personal-site repo.
Use `teaching/install_ai/REPO_MAP.md` as the canonical ownership map for the current website and starter-pack situation.

This is a starter pack, not a locked system. Users can use it as-is, copy parts, or start a new folder.

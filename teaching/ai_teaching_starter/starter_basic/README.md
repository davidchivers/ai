# AI teaching starter (basic)

Use this if you want the lightest workshop setup.

Open this file first, then open `memory/README.md`.

## What this pack is for

- A simple first setup for VS Code or Cursor.
- A small set of agents and skills.
- One example project template you can copy and adapt.

## What each top-level folder is for

- `agents/`: reusable specialist prompts for common tasks.
- `skills/`: reusable workflow guides.
- `memory/`: persistent notes for you and the AI assistant.
- `projects/_project_template/`: copy this folder to start a real project.
- `templates/`: shared document skeletons such as referee responses.

## First 5 minutes

1. Open this folder in VS Code or Cursor.
2. Read `memory/README.md`.
3. Copy `projects/_project_template/` to a new project folder.
4. Open your copied project folder.
5. Start in `notes/brainstorm.md`.
6. Move chosen decisions into `notes/research_plan.md`.

## What to ignore at first

- You do not need to read every file.
- For a first workshop run, focus on `README.md`, `memory/README.md`, and your copied project folder.

## Included

- Core agents: empirical ideas, literature review, status updates.
- Core skills: ideation, literature, Stata cleaning/regression, LaTeX model writing.
- Basic templates: referee response skeletons.

This is a starter pack, not a locked system. You can use it as-is, copy only parts of it, or start a new folder anytime.

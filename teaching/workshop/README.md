# Workshop demo folder

This folder is a staged set of files for the AI workshop live demo.

## What it is for

- Keep the demo materials in one place at the top of the workspace.
- Open files in numeric order during the session.
- Avoid hunting through the full repo while presenting.

## Important note

- Most files here are copied demo examples, not the canonical originals.
- You can rename, reorder, add, or remove files here freely for the workshop.

## Editing demo

- `03 - editing - UPDATED.pdf` is tied to the LaTeX example in `02 - viewing - example_math/`.
- If you edit `example_math.tex` and recompile it in that folder, `UPDATED.pdf` will refresh.

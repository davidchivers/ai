# AI teaching starter (advanced)

Use this if you want a fuller workshop setup with stronger defaults.

Open this file first, then open `memory/global_notes.md`.

## What this pack is for

- A fuller setup for people who want more structure from the start.
- More agents and skills than the basic pack.
- Stronger workflow defaults for notes, naming, and project hygiene.

## What each top-level folder is for

- `agents/`: reusable specialist prompts for common tasks.
- `skills/`: reusable workflow guides.
- `memory/`: stable workflow preferences and persistent notes.
- `projects/_project_template/`: copy this folder to start a real project.
- `standards/`: conventions for notes, project structure, and status tracking.
- `templates/`: shared document skeletons such as referee responses.

## First 5 minutes

1. Open this folder in VS Code or Cursor.
2. Read `memory/global_notes.md`.
3. Copy `projects/_project_template/` to a new project folder.
4. Open your copied project folder.
5. Work in `notes/01_project_overview.md` to `notes/04_empirical_notes.md` while exploring.
6. Keep `notes/05_research_plan.md` as the decision-lock file.

## What is extra compared with Basic

- More agents and skills.
- Numbered notes files instead of a two-file notes setup.
- Explicit standards for notes structure and project hygiene.

## What to ignore at first

- You do not need to read every standard immediately.
- For a first workshop run, focus on `README.md`, `memory/global_notes.md`, and your copied project folder.

This is a starter pack, not a locked system. You can adapt the structure as needed.

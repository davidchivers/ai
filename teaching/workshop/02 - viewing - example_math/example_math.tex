This is a tiny LaTeX example for the workshop.

An inline expression looks like $y = ax + b$.

A displayed equation looks like
\[
  y = \alpha + \beta x + \varepsilon.
\]

Here is a short optimization problem:
\[
  \max_{c_t, a_{t+1}} \; u(c_t) + \beta V(a_{t+1})
\]
subject to
\[
  c_t + a_{t+1} = (1+r)a_t + w_t.
\]
